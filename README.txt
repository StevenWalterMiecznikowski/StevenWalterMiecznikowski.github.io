STEVEN MIECZNIKOWSKI PORTFOLIO

This is a self-contained static website. No paid software or hosting is required.

To publish for free:
1. Create a free account at GitHub.
2. Create a new repository named steven-miecznikowski-portfolio.
3. Upload index.html and the images folder.
4. In Settings > Pages, choose Deploy from a branch, then select main / root.
5. GitHub will give you a free public site address.

Before publishing, replace the placeholder contact text in index.html with the artist's actual email/social links.
